# UT2 — Control de flujo y funciones

Orden: operadores → condicionales (U01–U05 como C++/C#) → bucles (U01–U04; break/centinela en u05repaso) → funciones (`u04metodos`) → repaso UT1+UT2 → depuración.

En C se dice **función**, no método. La carpeta `u04metodos` existe por paridad con Java/C#/C++.

`u05repaso` **no** cierra la EV1: faltan cadenas y structs. El cierre está en [`../ut4_tiposcompuestos/u01enumstructtypedef/teoria/U07_CierreEv1.c`](../ut4_tiposcompuestos/u01enumstructtypedef/teoria/U07_CierreEv1.c).
