# EV2 — Arrays, punteros, memoria y ficheros (C)

Orden oficial: **UT6 → UT7 → UT8 → UT9** (tras el cierre de EV1 en UT5 examenes). Nativo C11 (no POO, no STL).

| UT | Carpeta | Tema |
|----|---------|------|
| **UT6** | `ut6_arrays` | Arrays 1D/2D, bucles, paso a funciones |
| **UT7** | `ut7_punteros` | `*`, `&`, `NULL`, aritmetica, arrays como punteros |
| **UT8** | `ut8_memoriadinamica` | `malloc` / `calloc` / `realloc` / `free` |
| **UT9** | `ut9_ficheros` | `FILE *`, texto/binario, errores |

(Futuro: **UT10** `ut10_examenesev2` — ultima unidad de EV2 para examenes.)

Compilar:

```powershell
gcc -std=c11 -Wall -Wextra -pedantic fichero.c -o prog -lm
.\prog
```
