# Tests interactivos — C (EV1 hasta bucles)

Tests tipo examen en HTML + JavaScript (sin backend). El alumno elige **tema**, responde con opción múltiple (A–D barajadas) y recibe feedback al instante.

## Cómo abrir

1. Abre `test_ev1_hasta_bucles.html` en el navegador (doble clic o *Live Server*).
2. El JS debe estar en la misma carpeta: `test_ev1_hasta_bucles.js`.

Copia desplegada en el portal (GitHub Pages): `portfolio/public/tests/c-ev1/` (misma pareja de ficheros).

## Plantilla

El sistema está copiado de `linux/ra3/tests/` (SMR RA3). Convenciones para nuevos tests: `.cursor/rules/tests-interactivos-html.mdc`.
