# EV1 — Cliente web y JavaScript básico

**Evaluación 1.ª** · Trimestre 1 · Peso orientativo: **30–35 %** del módulo

## Resultados de aprendizaje

| RA | Cobertura en EV1 |
| --- | --- |
| **RA 1** | Completo |
| **RA 2** | Completo |
| **RA 3** | Inicio (consola, primeros objetos globales) |

## Unidades

### ut1-cliente-web (RA 1)

- Modelo cliente / servidor y rol del navegador
- Ejecución de scripts: interno, externo, defer/async
- DevTools: consola, Elements, Network
- Integración `<script>` + HTML
- Herramientas: VS Code, extensiones, Live Server

**Al terminar la UT:** explicar dónde se ejecuta el JS y demostrar uso básico de DevTools.

### ut2-sintaxis-js (RA 2)

- `let`, `const`, tipos primitivos
- Operadores y conversiones
- `if` / `else`, `switch`
- `for`, `while`, `do…while`
- Comentarios y estilo básico

**Al terminar la UT:** programas en consola o con `alert`/`prompt` que usen decisiones y bucles.

### ut3-objetos-intro (RA 2 cierre + RA 3 inicio)

- `console.log`, `console.error`
- Introducción a `window` y `document` (lectura, no DOM avanzado)
- Errores de sintaxis y de runtime en consola

**Al terminar la UT:** leer mensajes de error y corregir scripts sencillos.

## Entregables típicos (referencia)

- Cuestionario teórico RA 1 (cliente web, HTTP básico)
- Práctica RA 2: ejercicios de sintaxis (10–15 problemas)
- Examen EV1: parte teórica RA 1–2 + práctica corta en navegador
