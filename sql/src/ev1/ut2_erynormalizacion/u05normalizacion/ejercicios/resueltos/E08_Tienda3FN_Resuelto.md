# E08_Tienda3FN (resuelto)

**Enunciado:** productos(id, nombre, categoria_nombre) — mejora 3FN.

## Solucion

Si categoria tiene datos propios: Categoria(id, nombre); Producto(id, nombre, id_categoria FK). Si categoria es solo etiqueta sin mas datos, a veces se deja.
