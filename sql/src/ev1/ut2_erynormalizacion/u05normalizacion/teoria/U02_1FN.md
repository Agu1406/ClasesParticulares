# 1FN — Primera forma normal

Una tabla esta en **1FN** si:

1. Todos los atributos son **atomicos** (un valor por celda).
2. No hay grupos repetitivos (telefono1, telefono2, telefono3...).

## Antes (mal)

```text
Cliente(id, nombre, telefonos)  -- telefonos = '6001,6002'
Pedido(id, productos)           -- 'Teclado;Raton'
```

## Despues

Tablas separadas / columnas atomicas; lineas de pedido en filas.

## Prueba tu

`direccion = 'Calle Mayor 1, Madrid'` — esta atomico si necesitas filtrar por ciudad?
