# 3FN — Tercera forma normal

- Esta en 2FN
- Ningun atributo no clave depende de otro **no clave** (sin transitivas).

## Ejemplo

```text
Empleado(id, nombre, id_dpto, nombre_dpto)
id → id_dpto → nombre_dpto
```

`id → nombre_dpto` es transitiva via id_dpto.

## Solucion

```text
Departamento(id_dpto PK, nombre_dpto)
Empleado(id PK, nombre, id_dpto FK)
```

## Meta de clase

Llegar a **3FN** en disenos de examen tipicos. Boyce-Codd se menciona, no se profundiza.
