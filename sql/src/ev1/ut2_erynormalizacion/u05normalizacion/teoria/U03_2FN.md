# 2FN — Segunda forma normal

- Esta en 1FN
- Todo atributo no clave depende de la **PK completa**, no de una parte.

Solo aplica de verdad cuando la PK es **compuesta**.

## Ejemplo

```text
Matricula(dni, codigo_curso, nombre_alumno, titulo_curso, nota)
PK (dni, codigo_curso)
```

Problemas:

- `dni → nombre_alumno` (parcial)
- `codigo_curso → titulo_curso` (parcial)

## Solucion

```text
Alumno(dni PK, nombre_alumno)
Curso(codigo PK, titulo_curso)
Matricula(dni FK, codigo FK, nota) PK(dni,codigo)
```
