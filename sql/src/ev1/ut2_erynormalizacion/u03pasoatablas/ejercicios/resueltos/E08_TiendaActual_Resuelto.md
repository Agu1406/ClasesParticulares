# E08_TiendaActual (resuelto)

**Enunciado:** Mira tienda UT1: pedidos tiene id_producto. Que cardinalidad implica por fila?

## Solucion

Cada fila de pedido es 1 producto (como linea). Un pedido 'logico' con varios productos serian varias filas o cabecera+lineas.
