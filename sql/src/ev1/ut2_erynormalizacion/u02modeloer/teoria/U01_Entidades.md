# Entidades

Una **entidad** es un objeto del mundo real (o del negocio) sobre el que guardamos informacion.

Ejemplos: `Cliente`, `Producto`, `Pedido`, `Alumno`, `Curso`.

- **Tipo de entidad:** la clase (Cliente).
- **Ocurrencia / instancia:** Ana Garcia, Luis Perez...

```text
[ Cliente ]     <- entidad (rectangulo en E/R clasico)
```

## Regla practica

Si puedes decir "un/una X" y tiene datos propios → candidato a entidad.

En una biblioteca: Libro, Ejemplar, Socio, Prestamo — cuales son entidades?
