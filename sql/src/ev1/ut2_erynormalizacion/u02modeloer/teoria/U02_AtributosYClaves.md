# Atributos e identificadores

Un **atributo** describe una propiedad de la entidad: `nombre`, `precio`, `email`.

## Tipos utiles en clase

| Tipo | Idea | Ejemplo |
|------|------|---------|
| Simple | un valor | precio |
| Compuesto | se puede partir | direccion (calle, ciudad) |
| Multivalor | varios valores | telefonos |
| Derivado | se calcula | edad a partir de fecha_nac |
| Opcional | puede faltar | email |

## Clave / identificador

Atributo (o conjunto) que **distingue** cada ocurrencia: DNI, `id_producto`.

En el E/R suele subrayarse el identificador.
