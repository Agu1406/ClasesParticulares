# BD practica UT3 — `tienda`

Mismo esquema que UT1. En XAMPP:

1. Arranca **MySQL** en el panel XAMPP.
2. Importa por CLI:
   ```text
   C:\xampp\mysql\bin\mysql.exe -u root < tienda_ut3.sql
   ```
3. O en phpMyAdmin: Importar > elegir `tienda_ut3.sql` > Continuar.

Usuario tipico XAMPP: `root` sin contrasena.
