# UT5 — POO, excepciones e I/O (C++)

Equivalente a Java/Python/C# `ut5_pooexcepcionesio`. Portado desde C# (Fase B).

| Subtema | Carpeta | Contenido |
|---------|---------|-----------|
| u01 | `u01poobasica/` | Una carpeta por teoria; el fichero se llama como la clase (`Persona/Persona.cpp`). `CabeceraCpp/` muestra `Vector2D.h` + `Vector2D.cpp`. |
| u02 | `u02excepciones/` | `try` / `catch`, `throw`, **Error** y `vector.at` |
| u03 | `u03ficherosio/` | Ficheros con `<fstream>` |
| u04 | `u04repaso/` | Repaso integrado |

Convención de `u01poobasica/teoria/`: una carpeta por clase (`Persona/`, `Libro/`, …). El `.cpp` se llama como la clase, no `U0X_…`. En `CabeceraCpp/` sí hay `.h` + `.cpp` (PDF POO). El resto de subtemas de UT5 sigue con `U{NN}_Nombre.cpp`.
