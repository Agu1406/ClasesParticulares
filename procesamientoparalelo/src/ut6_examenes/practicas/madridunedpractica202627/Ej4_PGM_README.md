# Ejercicio 4 — Filtrado PGM (pendiente material del curso)

El enunciado pide un ZIP del curso virtual con funciones C de lectura/escritura PGM.

Cuando tengas el ZIP:

1. Colócalo en esta carpeta (o `madrid/uned/`).
2. Implementa `aplicaFiltro`, variables `tIni` / `tFin`, tags `TagN`.
3. Uso: `mpirun -np K ./ej4 entrada.pgm numero_filtro salida.pgm`

Sin el ZIP no se puede completar el esqueleto de I/O oficial.
