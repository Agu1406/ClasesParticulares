## Modulo profesional

- **Modulo**: Programacion
- **Codigo**: 0485
- **ECTS**: 14

## Resultados de aprendizaje (RA)

1. Reconoce la estructura de un programa informatico.
2. Escribe y prueba programas sencillos aplicando fundamentos de POO.
3. Escribe y depura codigo usando estructuras de control.
4. Desarrolla programas organizados en clases (POO).
5. Realiza operaciones de entrada/salida con librerias del lenguaje.
6. Manipula informacion con tipos avanzados de datos.
7. Aplica caracteristicas avanzadas de lenguajes OO y entorno.
8. Utiliza bases de datos orientadas a objetos para persistencia.
9. Gestiona informacion en bases de datos con integridad y consistencia.
