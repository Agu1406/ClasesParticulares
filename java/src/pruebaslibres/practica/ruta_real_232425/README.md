# Ruta real 23-24-25 (Programación)

Esta carpeta agrupa práctica específica para preparar los exámenes más parecidos
a la convocatoria real (`programacion_prueba_libre_23.pdf`, `..._24.pdf`, `..._25.pdf`).

## Objetivo

- Practicar con enfoque de examen reciente.
- Reforzar preguntas tipo test con ejercicios cortos aplicados.
- Trabajar por simulacro y por bloque tipo RA.

## Estructura

- `sin_resolver/`: ejercicios con TODO.
- `resueltos/`: mismos ejercicios ya resueltos.

## Uso recomendado (sesión de estudio)

1. Haz un test de la ruta real en `teoria/index.html`:
   - `rutaRealSimulacroA/B/C` o bloque `rutaRealRAx`.
2. Apunta fallos.
3. Resuelve el ejercicio de esta carpeta relacionado con esos fallos.
4. Revisa versión resuelta.
5. Repite con otro simulacro.

## Mapeo rápido test -> práctica

- Fallos de `args`, casting, operadores, `switch`, bucles:
  - `EjercicioRR01_FundamentosYControl`
- Fallos de POO, `static`, herencia, sobrecarga/sobrescritura:
  - `EjercicioRR02_POOYPolimorfismo`
- Fallos de excepciones, arrays, `try/catch/finally`:
  - `EjercicioRR03_ExcepcionesYArrays`
- Fallos de colecciones/JDBC/serialización y temas mixtos:
  - `EjercicioRR04_ColeccionesJDBCYFicheros`
