## Cobertura de bancos de test (2021-2025)

Esta coleccion se ha ampliado revisando los bancos `programacion2021..programacion2025`
para practicar en codigo los bloques que mas aparecen en test:

- Fundamentos, operadores, args y trazas de ejecucion.
- POO, herencia, static, constructores y enlace dinamico.
- Excepciones, `try/catch/finally`, arrays fuera de rango.
- Colecciones (`List`, `Set`, `Map`, `HashMap`) y duplicados.
- Recursion y wrappers (`==` vs `equals`).
- Serializacion/streams.
- JDBC y SQL basico.
- Refuerzo conceptual de JSON, ORM/HQL y JavaFX para preguntas teorico-practicas.

## Sugerencia de estudio
- Intenta resolver primero sin mirar.
- Ejecuta tus pruebas.
- Compara con la version resuelta y corrige.
