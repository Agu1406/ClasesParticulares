# Proyecto examen biblioteca API (UT7)

Tres variantes en esta carpeta (IntelliJ, modulo `java`):

| Carpeta | Contenido | Main |
|---------|-----------|------|
| `bili/` | Tienda consola SQLite + importacion JSON (Fake Store API) | `BiliApp` |
| `examenapi/` | CRUD consola biblioteca (API interna, SQLite) | `APIController` |
| `examenjdbc/` | Examen JDBC: DAO, CSV, restricciones UNIQUE | `ExamenBibliotecaMain` |

Librerias del modulo: **Sqlite**, **Jackson** (Bili), **Jakarta** (servlets UT7).
