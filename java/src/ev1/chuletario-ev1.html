8. Errores frecuentes

  • 5/2 → 2; usa 5.0/2.
  • String: equals, no ==.
  • Olvidar break en switch.
  • Media: (double)suma / c; si c==0.
  • Factorial: usar long.
  • class = nombre del archivo.
