1. TEORÍA PARA EXPLICAR (adaptada a 1º SMR)
✔ ¿Qué es una tarea programada?
Una tarea programada  es una acción que el sistema operativo 
ejecuta automáticamente en una fecha u horario determinado, sin 
que el usuario tenga que hacer nada.
Se utilizan para:
Crear copias de seguridad
Ejecutar scripts automáticamente
Actualizar programas
Limpiar archivos temporales
Apagar o reiniciar equipos en horario
✔ Diferencias entre Windows y Linux

3. PARTE PRÁCTICA EN UBUNTU (cron)
🎯 Objetivo
Programar un script que escriba la fecha en un archivo cada minuto.
✔ Teoría breve de cron
cron permite ejecutar tareas en Linux usando un formato de 5 
campos:
* * * * *
| | | | |
| | | | └── Día de la semana (0-6)
| | | └──── Mes (1-12)
| | └────── Día del mes (1-31)
| └──────── Hora (0-23)
└────────── Minuto (0-59)
✔ Para editar cron:
crontab -e
✔ Práctica 2: Crear un script y ejecutarlo cada minuto
1. Crear un script
En la carpeta Documentos del alumno:
nano ~/Documentos/fecha.sh

--- Page 3 ---
Contenido:
#!/bin/bash
echo "La fecha actual es: $(date)" >> ~/Documentos/registro.txt
Dar permisos de ejecución:
chmod +x ~/Documentos/fecha.sh
2. Añadir una tarea cron
Abrir cron:
crontab -e
Añadir al final:
* * * * * /home/usuario/Documentos/fecha.sh
(Sustituir usuario por su nombre real)
Guardar → esperar 2 minutos.
✔ Comprobación:
Abrir el archivo:
cat ~/Documentos/registro.txt
Deben aparecer nuevas líneas con la fecha cada minuto.
