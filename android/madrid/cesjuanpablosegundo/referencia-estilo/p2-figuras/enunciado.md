# PRÁCTICA: Trigonometría

Desarrollar una clase llamada Círculo que:

- Tenga un constructor con un parámetro double que representa el radio
- Tenga un método calcularArea que no recibe ningún parámetro y devuelve un double. (Pi *R2)
- Tenga un método calcularDiametro que no recibe ningún parámetro y devuelve un double. (2*r)

Desarrollar una clase llamada Rectangulo que:

- Tenga un constructor con dos parámetros de double que inicialice base y altura.
- Tenga un método calcularArea que no recibe ningún parámetro y devuelve un double. (base *altura)
- Tenga un método calcularPerimetro que no recibe ningún parámetro y devuelve un double. (2*(b+h))

Desarrollar una clase llamada Triangulo que:

- Tenga un constructor con 2 parámetros de tipo double que inicialice base y altura.
- Tenga un método calcularArea que no recibe ningún parámetro y devuelve un double. (b*a)/2
- Desarrollar una Figura que tenga todos los elementos comunes a las clases mencionadas en las clases anteriores

Desarrolla una clase Entrada que permita registrar figuras y operar con figuras (pidiendo datos mediante un menú de la misma forma que en el ejercicio de temas anteriores)

## Modificación

Realiza las modificaciones necesarias para que se aplique linea de herencia y que todas las figuras cuando estén creadas se guarden en una lista de datos
